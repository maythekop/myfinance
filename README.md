# Thai Stock Radar

ระบบคัดหุ้นคุณค่า/ปันผลใน SET100 รันอัตโนมัติบน GitHub (ฟรี) วิเคราะห์ 4 ชั้นต่อกัน

| ชั้น | ตอบคำถาม | ใช้อะไร |
|---|---|---|
| 1. ปัจจัยพื้นฐาน | หุ้นตัวไหน **ดี** | ด่านคัดออก + คะแนน 0–100 เทียบกับหุ้นกลุ่มเดียวกัน |
| 2. ราคาเหมาะสม | ราคาตอนนี้ **ถูกพอ** หรือยัง | มูลค่ายุติธรรมจากปันผล → โซนซื้อ / ราคาทบทวนขาย |
| 3. จังหวะทางเทคนิค | ราคากำลัง **ลงแรงหรือฟื้น** | RSI, เส้นค่าเฉลี่ย 50/200 วัน, จุดต่ำ-สูงรอบปี |
| 4. ข่าว | มี **เหตุการณ์** ที่ควรรอหรือไม่ | Google News + Gemini (หรือคำสำคัญ) |

ข่าวและเทคนิค **ไม่เปลี่ยนคะแนนพื้นฐาน** ใช้เพื่อตัดสินจังหวะและเตือนความเสี่ยงเท่านั้น

> ผลลัพธ์เป็นเครื่องมือช่วยคัดกรองและจัดลำดับความสนใจ ไม่ใช่คำแนะนำการลงทุน
> ตรวจงบการเงินและข่าวจากแหล่งทางการ (SET / ก.ล.ต.) ก่อนตัดสินใจทุกครั้ง

**วิธีติดตั้ง:** ดู [`docs/github-guide.md`](docs/github-guide.md) ทีละขั้นตอน

## สัญญาณที่ได้

| สัญญาณ | เงื่อนไข |
|---|---|
| **ซื้อ** | ผ่านด่านคัดออก + คะแนน ≥ 70 + ราคา ≤ โซนซื้อ + ไม่มีข่าวลบ |
| **รอข่าวคลี่คลาย** | เหมือน "ซื้อ" แต่มีข่าวลบระดับ 3 ขึ้นไป |
| **รอราคา** | คะแนน ≥ 70 แต่ราคายังสูงกว่าโซนซื้อ (บอกราคาเป้าหมายและระยะห่าง) |
| **ทบทวนขาย** | ราคาเกินมูลค่ายุติธรรม 20%, ปันผลลดเกิน 20%, ข่าวลบรุนแรง (ระดับ 4–5) หรือคะแนนตก 15 แต้ม |
| **เฝ้าดู** | คะแนน 55–69 |
| **คะแนนต่ำ / ไม่ผ่านเกณฑ์** | ไม่อยู่ในความสนใจ (แสดงเหตุผล) |

หมายเหตุจังหวะที่แนบไปกับสัญญาณ เช่น "RSI ต่ำ ขายมากเกินไป", "ใกล้จุดต่ำสุดรอบปี", "แนวโน้มยังเป็นขาลง ควรทยอยซื้อ", "มหภาคกดดันกลุ่ม"

## วิธีคิดราคาเหมาะสม

- **D0** = ปันผลเฉลี่ยต่อปีของ 3 ปีเต็มล่าสุด (ลดผลจากปันผลพิเศษปีเดียว)
- **วิธีปันผลคิดลด:** มูลค่า = D0 × (1 + g) ÷ (r − g) โดย r = ผลตอบแทนที่ต้องการ 8%, g = การเติบโตของปันผล 2%
- **วิธีกรอบอัตราปันผลในอดีต:** มูลค่า = D0 ÷ อัตราปันผลเฉลี่ย 5 ปีของหุ้นตัวนั้น
- **มูลค่ายุติธรรม** = ค่าเฉลี่ยของ 2 วิธี (ปรับเป็นแบบอื่นได้)
- **ซื้อได้ไม่เกิน** = มูลค่ายุติธรรม × (1 − 15%)  ·  **ราคาทบทวนขาย** = มูลค่ายุติธรรม × (1 + 20%)

ตัวอย่าง: D0 = 1.00 บาท, ปันผลเฉลี่ย 5 ปี = 5% → ปันผลคิดลด 17.00, กรอบปันผล 20.00 → มูลค่ายุติธรรม 18.50 → ซื้อได้ไม่เกิน 15.73 → ทบทวนขายที่ 22.20

## ค่าที่ปรับได้ (`config/settings.json`)

### 1. ขอบเขตหุ้น `universe`
| ค่า | ตั้งต้น | ความหมาย |
|---|---|---|
| index | SET100 | เปลี่ยนเป็น `SET50` ได้ |
| min_market_cap_mb | 10000 | มูลค่าตลาดขั้นต่ำ (ล้านบาท) |
| min_avg_turnover_mb | 50 | มูลค่าซื้อขายเฉลี่ยต่อวันขั้นต่ำ (ล้านบาท) |
| exclude_tickers | [] | หุ้นที่ไม่ต้องการ เช่น `["TRUE", "BTS"]` |

### 2. ด่านคัดออก `hard_filters`
| ค่า | ตั้งต้น | ความหมาย |
|---|---|---|
| min_dividend_years_of_last_10 | 7 | จ่ายปันผลอย่างน้อยกี่ปีใน 10 ปีเต็มล่าสุด |
| min_profitable_years_of_last_4 | 4 | ต้องมีกำไรกี่ปี (จากงบที่มี ไม่เกิน 4 ปี) |
| max_payout_ratio_pct | 100 | payout สูงสุด |
| max_de_ratio | 2.0 | หนี้สินต่อทุนสูงสุด (เท่า) |
| max_pe | 30 | P/E สูงสุด (ขาดทุนตกด่านอัตโนมัติ) |
| apply_de_to_financials | false | ใช้เกณฑ์ D/E กับธนาคาร/สินเชื่อหรือไม่ |

### 3. น้ำหนักคะแนน `pillar_weights` และ `metric_weights`
| เสา | ตั้งต้น | ตัวชี้วัดย่อย (น้ำหนักในเสา) |
|---|---|---|
| dividend ปันผล | 35 | อัตราปันผล 50, ความสม่ำเสมอ 30, ความยั่งยืนของ payout 20 |
| valuation มูลค่า | 25 | P/E 35, P/BV 30, อัตราปันผลปัจจุบันเทียบเฉลี่ย 5 ปี 35 |
| quality คุณภาพ | 25 | ROE 50, อัตรากำไรสุทธิ 25, ความนิ่งของกำไร 25 |
| strength ความแข็งแรง | 15 | D/E 50, current ratio 25, อัตราผลตอบแทนกระแสเงินสดอิสระ 25 |

ตัวเลขไม่จำเป็นต้องรวมได้ 100 ระบบจะเฉลี่ยตามสัดส่วนให้ ใส่ 0 เพื่อตัดตัวชี้วัดนั้นทิ้ง
ถ้าหุ้นตัวไหนไม่มีข้อมูลบางตัว ระบบเฉลี่ยจากตัวที่มี และแสดง `data_completeness_pct` ให้เห็น

### 4. วิธีให้คะแนน `scoring`
| ค่า | ตั้งต้น | ความหมาย |
|---|---|---|

| min_peers_for_sector_percentile | 4 | กลุ่มที่มีหุ้นน้อยกว่านี้จะเทียบทั้งตลาด |

### 5. ราคาเหมาะสม `fair_value`
| ค่า | ตั้งต้น | ความหมาย |
|---|---|---|
| method | blend | `blend` เฉลี่ย 2 วิธี, `min_of_both` เลือกต่ำกว่า (ระวังกว่า), `dividend_discount`, `yield_band` |
| dividend_base_years | 3 | เฉลี่ยปันผลกี่ปีเป็นฐาน D0 |
| required_return_pct | 8.0 | ผลตอบแทนที่ต้องการต่อปี (ยิ่งสูง มูลค่ายิ่งต่ำ) |
| long_term_div_growth_pct | 2.0 | การเติบโตของปันผลระยะยาว |
| margin_of_safety_buy_pct | 15 | ส่วนลดจากมูลค่ายุติธรรมที่ถือว่าเป็นโซนซื้อ |
| premium_trim_pct | 20 | ราคาสูงกว่ามูลค่าเท่าไรให้ทบทวนขาย |

### 6. จังหวะเทคนิค `timing_technical`
| ค่า | ตั้งต้น | ความหมาย |
|---|---|---|
| sma_short_days / sma_long_days | 50 / 200 | เส้นค่าเฉลี่ยใช้ดูแนวโน้ม |
| rsi_days | 14 | รอบคำนวณ RSI |
| rsi_oversold / rsi_overbought | 35 / 70 | เกณฑ์ขายมากเกินไป / ซื้อมากเกินไป |
| near_52w_low_pct | 10 | ห่างจุดต่ำสุดรอบปีไม่เกินกี่ % ถือว่า "ใกล้จุดต่ำ" |
| atr_days / chandelier_mult | 22 / 3.0 | Chandelier Exit รายวัน (ใช้หาจังหวะซื้อ): สูงสุด 22 วัน − 3 × ATR |
| chandelier_fresh_days | 5 | กลับเป็นขาขึ้นภายในกี่วันทำการ จึงแจ้งว่า "เพิ่งกลับตัว" |
| chandelier_weekly_weeks / chandelier_weekly_mult | 22 / 3.0 | Chandelier แบบแท่งสัปดาห์ (ใช้ดูแลหุ้นที่ถือยาว) |

**Chandelier Exit คืออะไร** ATR (Average True Range) คือระยะแกว่งเฉลี่ยต่อแท่งของหุ้นตัวนั้น
- เส้นตัดขาดทุน = ราคาสูงสุด n แท่ง − k × ATR · ขาขึ้นอยู่ ถ้าราคาปิดต่ำกว่าเส้นนี้ = แนวโน้มจบ
- เส้นกลับตัว = ราคาต่ำสุด n แท่ง + k × ATR · ขาลงอยู่ ถ้าราคาปิดเหนือเส้นนี้ = กลับเป็นขาขึ้น
- ระยะห่างปรับตามความผันผวนของหุ้นแต่ละตัว และเส้นขยับได้ทางเดียว (ขาขึ้นเส้นไม่ลดลง)
- รายวันไวพอสำหรับจังหวะซื้อ แต่แคบเกินสำหรับหุ้นปันผลที่ถือยาว จึงใช้แบบรายสัปดาห์ดูแลพอร์ต (หลุดเมื่อแนวโน้มระยะกลางเสียจริง)

### 7. กติกาสัญญาณ `timing_signal`
| ค่า | ตั้งต้น | ความหมาย |
